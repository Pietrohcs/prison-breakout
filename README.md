# PRISON BREAKOUT

Jogo 2D de fuga da prisão desenvolvido como projeto final da disciplina de Programação Web (ITPLSPW) no **IFSP — Campus Itapetininga**

🔗 **Jogue online:** https://pietrohcs.github.io/prison-breakout/

---

## Sobre o Jogo

No **Prison Breakout**, você controla um prisioneiro que precisa escapar por **3 alas diferentes da prisão** com dificuldade progressiva:
- **Nível 1:** Cela inicial com 1 guarda.
- **Nível 2:** Ala intermediária com 2 guardas e obstáculos centrais.
- **Nível 3:** Segurança máxima com 3 guardas e um item especial do **IFSP** que congela os guardas por 2 segundos.

---

## Como Jogar

- **Movimentar:** `W`, `A`, `S`, `D` ou `Setas do teclado`
- **Objetivo:** Pegue a **chave dourada** para destrancar a saída no topo e avance até escapar do Nível 3.
- **Reiniciar:** Pressione `R` após vencer ou ser capturado.
